# 🧠 Proyecto de Práctica SQL con DBeaver y PostgreSQL


## 🛠️ Herramientas utilizadas

- 🐘 **PostgreSQL** – Sistema de gestión de base de datos.
- 🐬 **DBeaver** – Interfaz para gestionar y ejecutar consultas SQL.
- 🐙 **GitHub** – Plataforma para documentación y control de versiones.

---

## 📚 Descripción del proyecto

Este repositorio contiene la resolución de **64 ejercicios de SQL**, diseñados para poner en práctica desde lo más básico hasta consultas complejas, usando una base de datos relacional ya estructurada.

Se trata de una **base de datos modelo** con varias tablas relacionadas entre sí, simulando un entorno real de gestión de alquileres de películas.

### 📋 Ejercicios desarrollados

Cada ejercicio aborda un objetivo concreto de aprendizaje, incluyendo:

- 🔍 Consultas básicas con una sola tabla.
- 🔗 Uso de **INNER JOIN**, **LEFT JOIN**, **RIGHT JOIN** y **CROSS JOIN**.
- 🧠 Aplicación de **subconsultas** en cláusulas `WHERE` y `FROM`.
- 🧾 Uso de **funciones agregadas** como `COUNT`, `AVG`, `SUM`, `STDDEV`, `VARIANCE`.
- 🧱 Creación y consulta de **vistas**.
- 📅 Manejo de **fechas y diferencias entre fechas**.
- 🧹 Aplicación de **buenas prácticas SQL**: uso de alias, orden de cláusulas, legibilidad del código.
- 📦 Consultas con **estructuras temporales** (tablas derivadas, subqueries).
- ✅ Validación y análisis de resultados esperados.

---

## 🧑‍💻 Buenas prácticas aplicadas

- Uso de alias descriptivos.
- Ordenación y tabulación para facilitar la lectura.
- Comentarios en el código para entender el propósito de cada consulta.
- Separación lógica entre ejercicios.
- Validación del resultado de cada consulta para asegurar la coherencia con el enunciado.
